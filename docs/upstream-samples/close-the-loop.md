The next feature is always easier to imagine than the last ten percent of the current one. Empty states, keyboard access, and error recovery are less glamorous than a new screen.

## Define done as a journey

A note is not saved because the form submitted. It is saved when you can reopen it and find the same words. A search is not finished because results render. It is finished when a person can reach one and return without losing their place.

## Leave a clean stopping point

Complete the smallest useful loop, write down what was verified, and make the next step visible. This creates something another person can assess without inheriting your entire mental state.

## Let the next idea wait

A list of future possibilities is healthy. Treating all of them as current requirements is exhausting. Put the next idea in a notebook and return to the thing you can finish today.
